# 麒麟长期助手

适用：`feat/running-agent-discovery`，2026-10-08 新增本机长期助手；角色资源沿用 3.0.2-keyboard-contact。实现与验收见 [交付报告](PR-REPORT-qilin-companion-2026-10-08.md)，桌宠设置与命令边界见 [领域约定](../CONTEXT.md)。

右键麒麟或托盘，选择 **麒麟长期助手**。快速对话中的 **交给麒麟** 会把当前输入带到任务面板。

## 交给麒麟

写清目标、提供的材料和允许持续负责的范围，再选择执行方式：

- **Codex 本机任务**：使用本机已安装并登录的 Codex CLI，沿用当前模型、认证和规则。选择工作目录；留空会创建独立任务目录。默认只读，勾选“允许修改所选工作目录”才使用 workspace-write。适合文件阅读、工具操作和项目工作；具体能力取决于本机 Codex 的配置与连接。
- **当前聊天模型**：使用 AI 设置中的模型、接口与凭据，适合整理已提供文字、写清单和分析资料。此执行方式没有文件、网页或电脑操作工具，需要补充资料时会等待你的回答。

可立即执行、指定时间执行一次、每小时、每24小时或自定义重复间隔。指定时间采用电脑当前时区，保存时换算成绝对时间。重复任务以首次运行时间为基准；休眠或桌宠关闭期间错过多个时点，只补做一轮，再等待未来时点。

“允许在等待变化时稍后跟进”允许模型为本任务保存下次检查时间。最短间隔60秒，最长30天，连续最多6次；到达上限后等待你的指示。重复周期另行保存，不受这6次上限代替。相同的跟进结果不会反复提醒。

## 任务与结果

面板显示排队、正在执行、等待下次运行、需要你的回答、暂停、完成、失败或停止状态。选择任务可查看工作目录、权限、最新指示、结果和错误原因。

- **暂停 / 停止**：取消当前执行，保留记录与已有结果。此前已经完成的文件修改不会被撤销。
- **继续任务**：可以先填写回答或追加要求；本机任务使用本任务保存的精确会话继续，文字任务带入最近结果和后续指示。
- **打开结果**：打开已落盘的 Markdown 文件。
- **移除记录**：移除任务；已有结果文件保留。

关闭面板后，后台任务仍在桌宠中运行。退出桌宠会停止它拥有的执行进程；重启后中断任务保持暂停，需要确认结果再继续，避免自动重做。已保存的定时任务会恢复调度。

任务完成、出现新进展、失败或需要回答时，会通过桌宠气泡和已有系统通知入口提醒。系统通知沿用桌宠的通知设置；点击通知打开对应任务。

## 长期记忆与活动记录

在“长期记忆”保存、编辑或删除偏好与事实，普通聊天和后续任务会在下一轮读取。模型给出的记忆候选显示在任务结果中，可自行选择保存。记忆不会自动授权新的操作。

最多保存80条记忆，每条1000字；每轮使用按保存顺序、完整条目组成的约8000字符记忆上下文。最多保留100项任务和最近300条活动；单个状态文件上限16 MiB。进度落盘最多每2秒一次，会话标识首次到达时立即保存。结果文件会保留，可自行备份和整理。

## 数据与恢复

主实例数据在 `%APPDATA%/dsh-pet-standalone-webm-chat/companion/`；独立实例使用 `companion-<instance_id>/`。`state.json` 保存任务、记忆和活动，`outputs/<task_id>/<run_id>.md` 保存结果，`run-data/<run_id>/` 保存执行协议文件。

使用进程锁避免同一数据目录重复调度，状态写入采用临时文件、fsync与原子替换。最多同时执行2项任务；本机任务的工作目录重叠时会串行。记录损坏时保留原文件并显示原因；调度保存失败后停止执行，检查空间与文件权限后重启桌宠。

## 与 Your dot 的范围对应

参考 [Your dot](https://learn.chatgpt.com/docs/dots)、[任务与记忆](https://learn.chatgpt.com/docs/dots/tasks-and-memory) 和 [电脑与应用](https://learn.chatgpt.com/docs/dots/computers-and-apps)。本版实现本机后台任务、定时与自主跟进、长期记忆、补充指示、活动/结果中心和主动提醒。

电脑关机时运行、云端常驻、跨设备共享、Slack/Teams 接入等依赖外部服务，本版没有这些服务。本机文件和工具能力依赖 Codex CLI；聊天模型仅提供文字能力。Windows 已实机验收；其他操作系统没有本轮实机证据。
